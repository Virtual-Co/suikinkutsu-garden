# Suikinkutsu Garden

A browser sound toy that lets you tune a buried garden pot and play a short note-matching game. Click the target note to hear it, adjust the pot, then drop water to hear your tuned resonance and check the match.

The demo fuses the paper’s six-descriptor approach to characterizing suikinkutsu recordings with an original Web Audio synthesis toy and target-note game. The synthesized tones and four target notes are illustrative, authored for this demo, and are not recordings or measured profiles from the paper’s nine sites. The toy does not reproduce the paper’s analysis pipeline or claim physical accuracy.

## Run

Open `demo/index.html` in a modern browser. Audio begins only after a user gesture. The demo makes no network requests and uses no external assets or libraries.
